# KolAman

הסבר מה קורה עם הודעה שכבר קיימת ברדיס:

הבדיקה נעשית ע"י השוואת השדות של הקווי אורך ורוחב וכותרת.

כיון שמוגדר שלהודאות יש תוכלת חיים של דקה כי יש סבירות שאחרי דקה יתקבל דיווח אמת על מקרה שחוזר על עצמו.

הסבר על הולידציה:

בדיקה שכל השדות הנכונים קיימים.

בדיקה שהשדות של המסםרים הם באמת מספרים.

בדיקה שהערכים של הנ"צ הם בטווח התקין.

בדיקה שערכים קטגוריים לא סוטים מהערכים המוסכמים.

בדיקה שהכותרות מתאימות לכל מדווח.
